## About

Continuum Bio Analysis is a web-based structural perturbation analysis tool for comparing the modeled effects of medical conditions and compounds using the SEAM runtime.

- Frontend: single-page HTML/CSS/JavaScript application
- Backend options: Python and C HTTP servers included in this repository
- Data: compound, condition, and structure databases
- Purpose: educational and research use only; results are not medical advice

For setup and technical details, see [README.md](README.md), [QUICKSTART.md](QUICKSTART.md), and [ARCHITECTURE.md](ARCHITECTURE.md).
